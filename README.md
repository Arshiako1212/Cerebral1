# CerebralSupport روی Railway (با پایگاه‌داده PostgreSQL)

## فایل‌ها
- `index.html` : خود اپ (همان وب‌اپ؛ اگر سرور پیدا نشود با ذخیره‌ی محلی کار می‌کند)
- `server.js` : سرور Node.js که صفحه را می‌دهد و اطلاعات را در PostgreSQL ذخیره می‌کند
- `package.json` : وابستگی‌ها (فقط `pg`) و فرمان اجرا (`npm start`)
- `railway.json` : تنظیم اجرا و بررسی سلامت (`/api/health`)

## مراحل راه‌اندازی
1. همه‌ی این فایل‌ها را در ریشه‌ی یک مخزن GitHub بگذار (Add file ← Upload files).
2. در railway.com با GitHub وارد شو ← **New Project** ← **Deploy from GitHub repo** ← مخزن را انتخاب کن.
3. داخل همان پروژه: **+ New ← Database ← Add PostgreSQL**.
4. روی سرویس برنامه (نه دیتابیس) برو ← تب **Variables** و این سه متغیر را اضافه کن:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`  (اسم `Postgres` باید دقیقاً با اسم سرویس دیتابیس در Railway یکی باشد)
   - `APP_PASSWORD` = رمز ورود به اپ (مثلاً یک جمله‌ی بلند)
   - `SESSION_SECRET` = یک متن تصادفی طولانی (حداقل ۳۲ حرف)
5. تب **Settings ← Networking ← Generate Domain**. لینک https ساخته می‌شود.
6. لینک را باز کن، رمز را بزن و استفاده کن. جدول‌ها خودکار ساخته می‌شوند.

## حساب کاربری و ادمین
- هر کسی می‌تواند ثبت‌نام کند: نام، نام خانوادگی، شماره تلفن و رمز (حداقل ۶ حرف). ورود با شماره تلفن و رمز است.
- اگر شماره تلفن قبلاً ثبت شده باشد (حتی با ارقام فارسی یا به‌صورت +98) پیام «قبلاً ثبت‌نام کرده‌اید» می‌آید. تشخیص تکراری فقط با شماره تلفن است؛ نام و نام خانوادگی بررسی نمی‌شود.
- هر کاربر فقط بیمارها و جلسه‌های خودش را می‌بیند.
- ادمین: نام کاربری `admin` و رمزش همان مقدار `APP_PASSWORD` در Variables است. پنل ادمین فهرست کاربران، بیماران هر کاربر، میزان پیشرفت، خروجی Excel و پشتیبان کل، تغییر رمز و حذف کاربر را دارد.
- رمز کاربرها به‌صورت هش‌شده (scrypt) ذخیره می‌شود و حتی ادمین هم آن را نمی‌بیند؛ فقط می‌تواند رمز جدید بگذارد.
- بیمارهایی که قبل از این نسخه (بدون حساب) ثبت شده بودند به هیچ کاربری وصل نیستند و دیده نمی‌شوند.

## نکته‌ها
- `PORT` را Railway خودش می‌دهد؛ چیزی تنظیم نکن.
- دیدن جدول‌ها: روی سرویس Postgres ← تب **Data**.
- اتصال از کامپیوتر خودت: در Settings ← Networking دیتابیس، Public Access را روشن کن و آدرس عمومی را بردار. بعد از کار خاموشش کن.
- انتقال داده‌های قدیمی: در اپ قدیمی «پشتیبان‌گیری» بزن، بعد با حساب خودت وارد اپ جدید شو و «بازیابی» کن (به بیماران همان حساب اضافه می‌شود).
- اطلاعات بیماران حساس است: رمز قوی بگذار و گاهی پشتیبان بگیر.
